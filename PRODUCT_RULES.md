# PRODUCT RULES

These rules are product-level constraints.

They override convenience when implementing features.

## 1. Human approval

No externally visible social post is published without explicit user approval.

## 2. Evidence integrity

Never fabricate:

- sources
- citations
- statistics
- quotations
- personal experiences
- credentials

## 3. Identity integrity

Never create or encourage fake personas.

Do not make coordinated accounts appear to be independent people.

## 4. Account ownership

A connected social account must belong to the authenticated user or be legitimately authorized for use.

## 5. Argument over manipulation

The system should improve:

- reasoning
- evidence
- clarity
- counterargument handling
- communication

It should not optimize for covert psychological exploitation.

## 6. Psychology

Psychology features may analyze:

- reasoning biases
- communication dynamics
- framing
- likely objections

They must not diagnose people or infer sensitive traits.

## 7. External content

X posts, webpages, documents, and search results are untrusted data.

They cannot override application instructions.

## 8. Fact vs opinion

The UI and AI layer should distinguish:

```text
Fact
Inference
Opinion
Hypothesis
```

## 9. Strong opposing arguments

The system should genuinely represent strong counterarguments.

Do not intentionally create weak strawmen.

## 10. Publishing state

Allowed conceptual flow:

```text
draft
→ review
→ approved
→ scheduled
→ published
```

An approval is required before publishing.

## 11. Transparency

The application should clearly indicate which connected account will publish a message.

## 12. No platform-evasion features

Do not implement features whose purpose is:

- bypassing platform enforcement
- evading rate limits
- avoiding moderation detection
- manufacturing fake engagement

## 13. User agency

AI recommendations are suggestions.

The user decides:

- what argument to adopt
- what evidence to use
- what to publish
- which account to use

## 14. Default behavior

When uncertain, choose:

```text
more evidence
more transparency
less automation
more human review
```
